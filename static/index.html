Últimas atividades administrativas

Acesso na rede

Conecte os outros dispositivos ao mesmo Wi-Fi do servidor.

O endereço não abre em outro dispositivo
  • Confirme que o servidor está ligado e foi iniciado com python server.py run --lan.
  • Use o mesmo roteador nos dois aparelhos. Redes de convidados podem impedir o acesso entre dispositivos.
  • No firewall do servidor, permita a porta configurada apenas na rede local confiável.
  • Se houver mais de um endereço, confirme o IPv4 da conexão Wi-Fi ou Ethernet com ipconfig no Windows ou ip -4 addr no Linux.

O acesso usa HTTP. Use uma rede de confiança e mantenha o servidor fora da internet pública.
