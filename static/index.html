ACESSO ENTRE APARELHOS

Conecte sua família.

O servidor funciona sem internet, mas os dispositivos devem estar conectados à mesma rede local.

01

Inicie o servidor

No computador ou Raspberry Pi, execute python server.py run --lan. Deixe o equipamento ligado.

02

Entre no mesmo Wi-Fi

Conecte os celulares e notebooks ao mesmo roteador ou ponto de acesso local. O roteador não precisa ter internet.

03

Abra o endereço

No navegador de cada celular, digite o endereço IPv4 mostrado no terminal do servidor, como http://192.168.1.10:8765.

04

Use a conta de leitura

O usuário familia, se criado, pode consultar e baixar arquivos. Somente administradores podem adicionar ou apagar.

ENDEREÇO DESTA SESSÃO—

Se estiver em outro aparelho, o IP pode ser diferente. Use o IP exibido no servidor.

⚠ Segurança importante

Este protótipo funciona por HTTP na rede local: senhas e dados em trânsito não têm criptografia de transporte. Use rede Wi-Fi confiável com WPA2/WPA3 e não exponha a porta 8765 à internet. Não coloque senhas bancárias ou documentos sensíveis neste servidor: para isso, prefira um cofre local criptografado.

Wikipédia offline com ZIM

Arquivos .zim podem ser importados na biblioteca e baixados em outros aparelhos. Para ler os artigos diretamente no navegador da rede, instale e execute o kiwix-serve separadamente, apontando para a pasta que contém os arquivos ZIM originais.

kiwix-serve --port=8080 /caminho/para/arquivos.zimExemplo ilustrativo no Linux
